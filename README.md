## Contribution to the project
 
Do you dare to collaborate? Follow these steps: 

1. Make a *fork* of this repository (button in the top right of GitHub). 
2. Clone your fork: 

git clone git@github.com:cuddlyJester/super-octo-carnival1223.git
    
3. Create a new branch: 

git checkout -b feature/new-section 

4. Make your changes, commit them and push the branch: 
git add . 
git commit -m "feat: add new section" 
git push -u origin feature/new-section 


5. On GitHub, open a *pull request* from your branch to the `main` branch of the original repository.
